# Agentic-Patient-Risk-Intelligence-Summarization-Matrix
The purpose of this project is to build an Agentic AI model that classifies clinical documents by specialty, summarizes with a timeline, and scores risk, with a human reviewing every output. Key Practices to implement in this project are Deterministic-first computation, span-grounded claims with a mechanical verifier, Instructor with bounded retries (error codes only, never failed text), fail closed to a human, eval-first golden set with CI regression gate and pinned model/prompt versions, measured de-id recall plus a canary no-leak test, treat note text as untrusted (prompt injection), hash-chained audit with model and prompt versions, 6-year retention, RBAC and encryption, track reviewer override rate and random second-review sampling against rubber-stamping.
